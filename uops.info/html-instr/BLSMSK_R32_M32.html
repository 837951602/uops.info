BLSMSK (R32, M32)

Summary: "Get Mask Up to Lowest Set Bit"
Reference: https://www.felixcloutier.com/x86/blsmsk
Extension: BMI1
Category: BMI1
ISA-Set: BMI1
CPL: 3
iform: BLSMSK_GPR32d_MEMd
iclass: BLSMSK
ASM: BLSMSK

Operands

  • Operand 1 (w): Register (EAX, ECX, EDX, EBX, ESP, EBP, ESI, EDI, R8D, R9D, R10D, R11D, R12D, R13D, R14D, R15D)
  • Operand 2 (r): Memory
  • Operand 3 (w, suppressed): Flags (AF: undef, CF: w, OF: w, PF: undef, SF: w, ZF: w)
