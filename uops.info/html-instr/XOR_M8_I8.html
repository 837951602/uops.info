XOR (M8, I8)

Summary: "Logical Exclusive OR"
Reference: https://www.felixcloutier.com/x86/xor
Extension: BASE
Category: LOGICAL
ISA-Set: I86
CPL: 3
iform: XOR_MEMb_IMMb_80r6
iclass: XOR
ASM: XOR

Operands

  • Operand 1 (r/w): Memory
  • Operand 2 (r): 8-bit immediate
  • Operand 3 (w, suppressed): Flags (AF: undef, CF: w, OF: w, PF: w, SF: w, ZF: w)
