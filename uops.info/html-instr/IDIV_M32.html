IDIV (M32)

Summary: "Signed Divide"
Reference: https://www.felixcloutier.com/x86/idiv
Extension: BASE
Category: BINARY
ISA-Set: I86
CPL: 3
iform: IDIV_MEMv
iclass: IDIV
ASM: IDIV

Operands

  • Operand 1 (r): Memory
  • Operand 2 (r/w, suppressed): Register (EAX)
  • Operand 3 (r/w, suppressed): Register (EDX)
  • Operand 4 (w, suppressed): Flags (AF: undef, CF: undef, OF: undef, PF: undef, SF: undef, ZF: undef)
