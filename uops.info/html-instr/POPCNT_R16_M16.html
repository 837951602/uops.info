POPCNT (R16, M16)

Summary: "Return the Count of Number of Bits Set to 1"
Reference: https://www.felixcloutier.com/x86/popcnt
Extension: SSE4
Category: SSE
ISA-Set: POPCNT
CPL: 3
iform: POPCNT_GPRv_MEMv
iclass: POPCNT
ASM: POPCNT

Operands

  • Operand 1 (w): Register (AX, CX, DX, BX, SP, BP, SI, DI, R8W, R9W, R10W, R11W, R12W, R13W, R14W, R15W)
  • Operand 2 (r): Memory
  • Operand 3 (w, suppressed): Flags (AF: w, CF: w, OF: w, PF: w, SF: w, ZF: w)
