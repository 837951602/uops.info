CMP (R16, M16)

Summary: "Compare Two Operands"
Reference: https://www.felixcloutier.com/x86/cmp
Extension: BASE
Category: BINARY
ISA-Set: I86
CPL: 3
iform: CMP_GPRv_MEMv
iclass: CMP
ASM: CMP

Operands

  • Operand 1 (r): Register (AX, CX, DX, BX, SP, BP, SI, DI, R8W, R9W, R10W, R11W, R12W, R13W, R14W, R15W)
  • Operand 2 (r): Memory
  • Operand 3 (w, suppressed): Flags (AF: w, CF: w, OF: w, PF: w, SF: w, ZF: w)
