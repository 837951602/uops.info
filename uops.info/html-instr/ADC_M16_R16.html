ADC (M16, R16)

Summary: "Add With Carry"
Reference: https://www.felixcloutier.com/x86/adc
Extension: BASE
Category: BINARY
ISA-Set: I86
CPL: 3
iform: ADC_MEMv_GPRv
iclass: ADC
ASM: ADC

Operands

  • Operand 1 (r/w): Memory
  • Operand 2 (r): Register (AX, CX, DX, BX, SP, BP, SI, DI, R8W, R9W, R10W, R11W, R12W, R13W, R14W, R15W)
  • Operand 3 (r/w, suppressed): Flags (AF: w, CF: r/w, OF: w, PF: w, SF: w, ZF: w)
