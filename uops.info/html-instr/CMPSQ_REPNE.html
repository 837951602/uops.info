CMPSQ_REPNE

Summary: "Repeat String Operation Prefix"
Reference: https://www.felixcloutier.com/x86/rep:repe:repz:repne:repnz
Extension: LONGMODE
Category: STRINGOP
ISA-Set: LONGMODE
CPL: 3
iform: REPNE_CMPSQ
iclass: REPNE_CMPSQ
ASM: REPNE CMPSQ

Operands

  • Operand 1 (r, suppressed): Memory
  • Operand 2 (r, suppressed): Memory
  • Operand 3 (r/w, suppressed): Register (RCX)
  • Operand 4 (r/w, suppressed): Flags (AF: cw, CF: cw, DF: r, OF: cw, PF: cw, SF: cw, ZF: r/cw)
