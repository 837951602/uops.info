POPF

Summary: "Pop Stack Into EFLAGS Register"
Reference: https://www.felixcloutier.com/x86/popf:popfd:popfq
Extension: BASE
Category: POP
ISA-Set: I86
CPL: 3
iform: POPF
iclass: POPF
ASM: POPFW

Operands

  • Operand 1 (r/w, suppressed): Register (RSP)
  • Operand 2 (r, suppressed): Memory
  • Operand 3 (r/w, suppressed): Flags (AC: w, AF: w, CF: w, DF: w, ID: w, IF: w, IOPL: r/w, NT: w, OF: w, PF: w, RF: w, SF: w, TF: w, VIF: w, VIP: r, VM: r, ZF: w)
