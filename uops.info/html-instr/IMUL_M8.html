IMUL (M8)

Summary: "Signed Multiply"
Reference: https://www.felixcloutier.com/x86/imul
Extension: BASE
Category: BINARY
ISA-Set: I86
CPL: 3
iform: IMUL_MEMb
iclass: IMUL
ASM: IMUL

Operands

  • Operand 1 (r): Memory
  • Operand 2 (r, suppressed): Register (AL)
  • Operand 3 (w, suppressed): Register (AX)
  • Operand 4 (w, suppressed): Flags (AF: undef, CF: w, OF: w, PF: undef, SF: undef, ZF: undef)
