SBB (R64, M64)

Summary: "Integer Subtraction With Borrow"
Reference: https://www.felixcloutier.com/x86/sbb
Extension: BASE
Category: BINARY
ISA-Set: I86
CPL: 3
iform: SBB_GPRv_MEMv
iclass: SBB
ASM: SBB

Operands

  • Operand 1 (r/w): Register (RAX, RCX, RDX, RBX, RSP, RBP, RSI, RDI, R8, R9, R10, R11, R12, R13, R14, R15)
  • Operand 2 (r): Memory
  • Operand 3 (r/w, suppressed): Flags (AF: undef, CF: r/w, OF: w, PF: w, SF: w, ZF: w)
