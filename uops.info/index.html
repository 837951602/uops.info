Latency, Throughput, and Port Usage Information

For Instructions on Recent x86 Microarchitectures

This website provides more than 800,000 pages with detailed latency, throughput, and port usage data for most instructions on many recent x86 microarchitectures. While such data is important for understanding, predicting, and optimizing the performance of software running on these microarchitectures, most of it is not documented in the official processor manuals.
