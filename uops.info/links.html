Links to Related Resources

  • nanoBench
    nanoBench is a Linux-based tool for running small microbenchmarks on recent Intel and AMD x86 CPUs. The microbenchmarks are evaluated using hardware performance counters. The reading of the performance counters is implemented in a way that incurs only minimal overhead.
  • Instruction tables by Agner Fog
    Provides lists of instruction latency, throughput, and port usage data for many x86 microarchitectures, including Intel, AMD, and VIA microarchitectures.
  • http://instlatx64.atw.hu/
    Latency and throughput data for various x86 CPUs. Measured using AIDA64.
  • AsmGrid
    Latency and throughput data for several recent x86 CPUs. The data was obtained using the CULT project.
  • https://gmplib.org/~tege/x86-timing.pdf
    Latency and throughput data for different x86 processors. Considers only integer instructions.
  • Intel 64 and IA-32 Architectures Optimization Reference Manual
    Contains latency and throughput data for a number of "commonly-used instructions."
  • Intel X86 Encoder Decoder (XED)
  • XED to XML converter
  • Intel Architecture Code Analyzer (IACA)
  • Google EXEgesis
  • Open Source Architecture Code Analyzer (OSACA)
  • LLVM Machine Code Analyzer (llvm-mca)
  • MAQAO (Modular Assembly Quality Analyzer and Optimizer)
  • Apple M1 Microarchitecture Research by Dougall Johnson
